# hep-bot guides

hep-bot quotes these pages: `@hep-bot help` folds them all into one reply, and
`@hep-bot help <topic>` posts one of them. Edit them here; the bot reads them from
`main` of hep-forge/.github on every request, so nothing needs re-rendering.

The first line of each page is its title, the second its one-line summary (shown in
the folded list). Keep the rest short: it is read in an issue comment.
